This board

  • Fans and the onboard thermal sensors come from the Nuvoton NCT6791D. The kernel driver is nct6775. CPU package temperature comes from coretemp.
  • Headers on the board are CPU_FAN, CPU_OPT, CHA_FAN1–3, H_AMP_FAN (about 3 A), W_PUMP, and the 5-pin EXT_FAN port for the fan extension card. The card adds three headers and three thermistors. Linux does not label them with those silkscreen names, so identify each one before trusting a curve.
  • H_AMP and W_PUMP should keep a high minimum duty. Mark the CPU header critical so it cannot be set below 20%.
  • The RGB header is a 12 V analog strip (G/R/B, 5050, 2 A, 2 m). It is not a 5 V addressable header. Onboard LEDs are split across the I/O cover, audio, PCIe, center, and rear edge.
  • Aura sits on the Super I/O SMBus. Stock Unraid does not expose that bus, so motherboard lighting appears only when OpenRGB can see the controller. USB lighting devices still work. Fan control does not depend on it.
  • If a curve’s sensor disappears, that header goes to the failsafe duty. Spun-down array disks drop to the header’s minimum instead, so the case can stay quiet at night.
